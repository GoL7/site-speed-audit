# Security Policy

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub: **Security → Report a vulnerability** on this repository
(https://github.com/shaymolina242-art/site-speed-audit/security/advisories/new).

You will get a reply within 7 days.

## Scope

This skill is read-only: it measures a live website and writes a report. It must never modify a site, its code, hosting, DNS or settings. Any behaviour that does so is a security bug - please report it.
